# Continuous knit waist and bounded jacket thickness

`WaistNeck.blend` continues [HipSeatMotionCandidate](../HipSeatMotionCandidate/README.md) with an editable knitted waist fit and a correction to the jacket's fabric shell. The slate/teal identity, existing anatomical walk, articulated hands, fitted cuffs and turned cotton leg hems remain present. This is an offline human-development checkpoint; the full human/landscape goal stays active.

The inherited jacket used Solidify's `NON_MANIFOLD` / `CONSTRAINTS` shell solver. In a later walking pose it produced a roughly 0.22 m edge and a long dark needle across the rear neck and jacket. A close render with the head's albedo removed retained the line, distinguishing it from a neck texture defect. Stage-by-stage geometry inspection showed the long needle first appearing at fabric thickness. The delivered jacket uses native `EXTRUDE` normal thickness, preserving the nominal 1.2 mm thickness and original source mesh. No head texture, UV or anatomical coordinate changes are needed for this defect.

`Continuous knitted waist fit` is one added shape key on the existing 4,992-control ribbed band. Its upper edge follows the actual subdivided jacket opening; its lower edge grades into the shorts' upper opening. The band blends from the pelvis at the lower edge into normalized weights from the actual jacket at the upper edge, and retains fine 0.25 mm modeled rib relief. The knit also uses native normal-extruded thickness. The maximum fitted control change and actual opening centers are recorded in `build-report.json`. Original control coordinates, earlier keys, UVs, packed maps and rig action remain preserved.

Run `build.py`, `render.py`, and `audit.py` with Blender 4.5.5 LTS using `--python-exit-code 1 --python`. `render.py -- --preview` creates 24 native frames for a two-second preview at 12 fps. Rendering uses the retained matched-camera helper in `HandArticulationCandidate/render.py`; custody hashing reuses the existing helper functions from `HipSeatMotionCandidate/audit.py`. The source file is `HipSeatMotionCandidate/HipSeat.blend`, SHA-256 `9775f815af14570a673dc000ea9535c05ef35f06c6b0aeea1260a3105396cb20`.

The cold audit checks original mesh/curve controls, mesh edges, all existing UVs and old key coordinates, all 31 packed maps, all 46 rest matrices and six full-rig poses. It permits only the named added waist key. At render subdivision levels, all 49 authored integer frames are checked for exact paired jacket shell displacement bounded by nominal thickness, bounded knit edges and sampled upper seam contact. These checks do not certify complete garment/body collision, self-intersection freedom or every animated subframe. Separate starter-outfit acceptance, stopped export/import preparation, runtime skeleton, first-hour, Phase 1L and beta gates retain their status.

Delivered cold measurements: 4,765 original mesh/curve control sets and 31 packed maps preserved. Maximum measured jacket shell-layer displacement is 1.200 mm; maximum sampled upper knitted seam distance is 0.650 mm across 49 authored poses.
