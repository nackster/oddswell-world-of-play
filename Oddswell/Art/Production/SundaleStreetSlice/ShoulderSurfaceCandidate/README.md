# Rounded shoulder and sewn-surface study

This native Blender continuation of [NativeWalkingStudy](../NativeWalkingStudy/README.md) rounds the jacket's shoulder-to-torso transition during the retained adult walk. It preserves the pelvis/chest counter-rotation, weight transfer, fixed limb lengths, narrow teal signal and warm OddsWell street composition. It is an offline development checkpoint; the human-realism goal remains active.

The jacket uses a localized native Smooth modifier. A native Shrinkwrap constraint in **Outside** mode keeps free cloth outside the moving anatomical support; held collar, cuff and hem controls are excluded. The constraint has a 7 mm control offset, which is not a claim of 7 mm rendered clearance. Sewn details follow a triangulated subdivision-level-2 jacket cage matching the rendered cloth resolution. Four raglan stitches are rebuilt along connected edges of the actual cloth-panel UV boundary, with native editable curves and evaluated mesh followers. Original source curves remain intact. This is rig-deformed authored cotton drape with a clearance constraint, not a moving cloth simulation.

## Reproduction and verification

Use Blender 4.5.5 LTS. Run `round_shape.py`, `clearance.py`, and `sewn_edges.py` sequentially, then `audit_rounded.py` and `render.py`, using `--python-exit-code 1 --python`. `render.py -- --preview` generates 24 numbered native frames for the two-second, 12 fps preview. The starting file is the retained `NativeWalkingStudy/NativeWalk.blend`, SHA-256 `c0be82b985ca4be23f38271e4dcdff6d93960c499e871d66723149d3a6636a22`. The builders locate the repository root and keep their outputs in this folder. No external asset is downloaded.

The fresh cold audit compares 4,720 original mesh/curve control sets, original UVs and shape-key coordinates, and all 31 packed source maps. It checks eleven articulated poses, positive sampled free-cloth signed distance, evaluated sole contact, fixed bone scales and measured flat-stance bounds drift. The nearest-surface sample is not a complete cloth self-intersection proof, every-subframe certificate or runtime compatibility test. Eight negative held-attachment samples inherited from the source remain explicitly reported. The derived seams and their added curve sources are separate from the original preserved controls.

An earlier rest-preserving smoothing trial left the sharp cloth fold and displaced sewn details. Local cloth smoothing without the clearance constraint produced negative free-cloth distances and was rejected. Neither rejected scene is delivered. This version is judged through the final renders and the delivered cold audit; positive clearance alone does not establish visual realism.

The existing starter-outfit acceptance and stopped export/import preparation remain authoritative. This work grants no runtime animation, final-art, physical first-hour, Phase 1L exit or beta-exit credit.
