# Visual Consistency

## Goal

Every OddsWell character, city, team, item, apartment, interface element, and promotional image should feel as though it belongs to the same authored universe.

## Canonical hierarchy

1. Approved art-direction rules.
2. Approved master character and item references.
3. Approved 3D production assets.
4. Exploratory generated images and videos.

When generated material conflicts with an approved rule or reference, the approved material wins.

## Visual bible requirements

Before producing a large asset library, define and approve:

- Character proportions and silhouette language.
- Face, hair, body, and clothing stylization.
- Item shape language and detail density.
- Material and surface treatment.
- Color palettes for the world, cities, and teams.
- Lighting, atmosphere, and weather rules.
- Camera, lens, composition, and presentation rules.
- Graphic-design, typography, icon, and logo rules.
- Explicit examples of what does not belong in the game.

## Character consistency workflow

1. Explore several visual directions.
2. Approve one character style and proportion system.
3. Create a master reference sheet with front, side, back, face, expression, clothing, scale, and color references.
4. Use the same approved reference set for later generations.
5. Store approved references and generation notes locally.
6. Build and validate the final character as a production-ready 3D asset.

## Item consistency workflow

1. Assign each item to a city, team, culture, manufacturer, or neutral world style.
2. Reuse approved shape, material, color, and detail rules.
3. Generate controlled variations from the same reference family.
4. Approve a concept sheet before 3D production.
5. Validate the final model beside existing approved characters and environments.

## Tool roles

### Higgsfield AI

Use for consistent character references, concept variants, item presentation, storyboards, cinematic previsualization, and image-to-video exploration. The project owner has an active subscription. Announce intended use before consuming paid generations.

### Conversational image generation

Use for rapid ideation, focused edits, mood exploration, and reference variations when it is faster to work directly in the development conversation.

### 3D production tools

Use Blender or the selected engine pipeline for final geometry, topology, UVs, materials, rigs, animations, LODs, collision, and optimization. Generated images guide production but do not replace these steps.

## Current decision

Do not generate large quantities of characters or items until the first city's art direction and the base character system are approved. Consistency is established with a small canonical reference set first.
